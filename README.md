# Fantasy Chess 3D

نسخه پایه شطرنج سه‌بعدی فانتزی برای موبایل و دسکتاپ.

- آفلاین دو نفره
- موتور قوانین chess.js
- رندر سه‌بعدی React Three Fiber
- ساختار آنلاین Supabase Realtime
- جدول اتاق‌های آنلاین در `supabase/schema.sql`
- ساختار آماده جایگزینی مدل‌های GLB/GLTF

## اجرا
npm install
npm run dev

## Supabase
مقادیر `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را در `.env.local` قرار دهید و SQL را در Supabase اجرا کنید.
